# One Wisdom

![](https://raw.githack.com/bGZo/assets/dev/2026/20260113223432663.webp)

This is a repo that provides a random quote from a collection of quotes, which is collected from weread and internet by myself.

If you like this project, please give it a star.

## Contributing

If you have some good quotes, please feel free to open a pull request to add them to the collection, even just issue!

You can add quotes in the `quotes` folder in markdown format. Please follow the existing format.
